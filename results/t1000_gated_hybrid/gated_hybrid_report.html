Disagreement-Gated Hybrid

The strategy-5 network runs every step unless the five-member committee disagrees too much before ignition. Then a stiff ODE solver takes over until the temperature has risen 50 K, and the network finishes the run. The same 36 cases and 5 seeds as before, 20 ms each.

How the gate works

1 · Query the committeeAt every step, all five members predict the next state from the current state, each with Wang projection and enthalpy temperature. The run's own seed is one of the five.
2 · Measure disagreementR = ‖std of the five steps‖ / (‖mean step‖ + 10⁻³), on T and BCT(Y) in training-σ units, smoothed by a 20 µs rolling median.
3 · GateWhile T < T₀ + 50 K, if R > 0.3 the run switches to Cantera and stays there. The solver uses the reference mechanism, reactor and tolerances, advancing 2 µs per step from the current state.
4 · Hand backOnce T ≥ T₀ + 50 K, the run's own network does the fast runaway and the post-flame part. The gate cannot fire again after that.

Cost: what this prototype does and does not show

Caveats and next steps

  • Small evaluation. Only five slow cases exist (3 test, 2 validation), all in one regime, and the threshold was set on two of them. More slow initial conditions near 1000 K are needed to put a real false-negative rate on the gate.
  • The handover point barely matters. Handing back at +50 K or +200 K gives the same τ₄₀₀ and 3.49 K vs 3.42 K mean RMSE, so once runaway has started the network handles it well.
  • Some residual error remains in the gated cases (8–17 K RMSE). It comes from the network's fast runaway after handover; τ₄₀₀ errors there are 0.1–1.0%.
  • Next steps. First, keep one solver alive while a run is gated, which should take the ODE cost from ms to µs per step. Second, run the committee only before ignition. Third, test the same gate in a setting where the ODE is expensive: a larger mechanism, or many cells in CFD.
