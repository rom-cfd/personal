Cantera vs NN NRMSE 표와 기존7×10 그림을 같은 IC 순서로 묶었다.

plots_and_NRMSE_tables.pdf는 총36페이지로, 홀수 페이지가 그림, 바로 다음 짝수 페이지가 해당 IC NRMSE 표다.
NRMSE_summary.pdf/png는 모든 모델이 완주한 동일 IC 집합에서 계산한 IC별 NRMSE의 중앙값이다.
공통 IC 15개: [4, 5, 7, 32, 39, 44, 45, 57, 64, 68, 69, 73, 74, 76, 88]. 전체 test는18개이며 미완주 수를 별도 표시했다.

NRMSE=sqrt(mean((Cantera−NN)^2))/sqrt(mean(Cantera^2)). 사용자 첨부 util.py의 _nrmse_1d(A=Cantera,B=NN,norm="rms")를 그대로 사용했다.
표는 무차원 비율이며 %를 곱하지 않았다. 모든 시간점은 같은 가중치다. 기존 오차 보고서의 사다리꼴 시간적분 대신 첨부 util.py와 같은 단순 평균을 적용했다.
미완주는 전체 RMSE/NRMSE를 비우고 가용 prefix 절대RMSE를 별도 기록했다. 미래 값을 채우지 않았다.
0이 아닌 일정한 Cantera 신호도 정상적으로 계산한다. N2를 상수라는 이유로 제외하지 않았다. 두 신호가 동일한 상수이면 원본 함수처럼0을 반환한다. Cantera RMS=0인데 NN에 오차가 있으면 원본 함수가 ValueError를 내므로 표에서는 N/A로 기록한다. 임의 분모나 epsilon 보정은 넣지 않았다. 절대RMSE·Cantera RMS·상태 코드를 CSV에 저장했다.
모든 모델이 완주한 공통 IC의 중앙값을 전체 요약에 표시했다. 평균·표준편차·사분위수·유효 개수도 CSV에 저장했다. 종 변수들을 임의로 평균해 단일 순위 점수로 만들지 않았다.
모델과 입력, repaired 보정, 단기10k·장기 종료점은 기존 그림과 동일하다. ANN은 혼합에서도10k를 유지하며 장기는 모두 평탄 미도달 시간상한 종료다.
원본 코드·데이터·모델·결과를 수정하지 않았고 새 학습이나 추론은 수행하지 않았다.
