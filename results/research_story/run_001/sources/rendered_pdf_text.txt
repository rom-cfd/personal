08 · 학습 손실 변경
Soft constraint는 학습 벌점이고, rollout 물리 보정과 다르다
실제 구현은 다음 상태의 원소량 오차에 대한 L1 벌점이다.
Loss = MSE(Δz_pred, Δz_true) + λ · mean[ Σ |A · (Y_pred − Y_true,next)| ]
구분 학습 soft constraint 평가 repaired
작동 시점 역전파할 손실에 추가 예측한 후보 상태를 매 스텝 수정
물리 정보 H/O/N 원소량 차이 비음수·원소 투영·엔탈피 온도 보정
이번 비교 λ=1, 10, 100, 1000 raw와 별도 평가·별도 표기
신경망 출력은 계속 상태 증분이다. 반응률을 직접 출력하도록 바꾼 실험은 아니다.

APPENDIX B · 수식과 용어
전처리 → 증분 예측 → 물리 상태 복원 → 자기 예측
시간마다 현재 상태를 다시 변환한다. “다음 상태”와 “증분”을 혼동하지 않는다.
1. 변환 E(T,Y) = [T/1000, Y^γ/γ]
2. 표준화 z = (E − μ_train) / σ_train
3. 증분 정답 Δz_true = z(t + 2 us) − z(t)
4. 다음 상태 z_pred,next = z_current + NN(current, condition)
5. 다중 스텝 L_K = mean_{k=1…K} MSE(z_pred,k, z_true,k)
NRMSE는 이 표준화 공간의 loss가 아니라, 복원된 물리 상태와 Cantera를 비교한 지표다.
